# Jotapemartking — Site Institucional

Landing page de alta conversão da **Jotapemartking**, agência de marketing digital focada em tráfego pago, branding premium e copywriting persuasivo.

## Como funciona

O site é uma página estática (`index.html`) — não precisa de build nem de dependências. Basta hospedar o arquivo.

## Estrutura

- `index.html` — página completa (HTML, CSS e JavaScript embutidos)

## Publicação na Vercel

1. Conecte o repositório à Vercel (já está conectado).
2. A Vercel detecta automaticamente o `index.html` na raiz e publica como site estático.
3. Não é necessário configurar comando de build nem framework.
